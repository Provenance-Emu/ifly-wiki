# Systems

iFly runs the Sega Dreamcast plus the arcade platforms it shares hardware with. Arcade systems need a BIOS; Dreamcast does not.

| System | BIOS | Notes |
| --- | --- | --- |
| Dreamcast | No BIOS | Consumer console. Runs on the built-in HLE BIOS; no BIOS file needed. |
| Naomi | BIOS required | Arcade board. Requires `naomi.zip`. |
| Naomi 2 | BIOS required | Upgraded arcade board. Requires `naomi2.zip`. |
| Atomiswave | BIOS required | Sammy arcade hardware. Requires `awbios.zip`. |
| System SP ("Spider") | BIOS required | Sega arcade system. Requires `segasp.zip`. |
| Game-specific boards | No BIOS | House of the Dead 2, Ferrari F355, Airline Pilots — optional per-game BIOS. |

See [BIOS Setup](bios.md) for where the files go.
